# Antigravity Python & SQLite Pipeline

Учебный проект по автоматизации сбора, очистки данных и сохранению их в реляционную базу данных.

## 🛠 Стек технологий:
* **Python** (библиотеки для парсинга и обработки текстов)
* **Pandas** (экспорт и структурирование данных в Excel/CSV)
* **SQLite** (управление локальной базой данных и SQL-запросы)
* **Git / GitHub** (контроль версий и портфолио)

## 📂 Что делает проект:
1. `pipeline.py` — парсит документы, убирает дубликаты и очищает ошибки.
2. `database_pipeline.py` — загружает очищенные данные в базу `railway.db`.
3. Позволяет делать SQL-выборки и анализировать объем перевозок.
